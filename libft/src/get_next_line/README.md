### Description:
the goal of this project is the creation of the function get_next_line(int fd).
The function takes as a parameter the file descriptor of the said textfile, it will
reads the textfile and returns a string containing a whole line. get_next_line(int fd) can be used in succecion to acquire every line on the textfile in it's own string variable.

### Instructions:
to use get_next_line(), the folder must contain a textfile and a "main" function to use it.
the open function must be used as such "int fd = open("test.txt", O_RDONLY)"
