### Description
the goal of this project is to recreate the printf function from the XXXX library,
it will recognise the following "%" commands and behave the same way as the original printf function : %s, %c, %x, %X, %d, %i, %u, %p, %%


### Ressources
Followed the tutorial https://42-cursus.gitbook.io/guide/1-rank-01/ft_printf

AI has been used as a debugging tool
